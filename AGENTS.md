# Working in this repo

Before doing anything else, read `docs/STATUS.md` (at least the top entry)
to see what's already in flight. Before ending your session, append an
entry to it. Full protocol: `docs/AGENT_WORKFLOW.md`.

This file mirrors `CLAUDE.md` — the two exist only because Codex and
Claude Code each auto-load a differently-named file. Keep them identical;
put any actual protocol changes in `docs/AGENT_WORKFLOW.md`, not here.
